# Python Log Analyzer

A beginner-friendly Python project that reads server log files and analyzes them.

## Features

- Counts INFO, WARNING and ERROR logs
- Finds common error messages
- Counts IP addresses
- Finds the most common error
- Calculates total log entries

## Technologies

- Python
- File Handling
- Dictionaries
- String Processing

## How to Run

```bash
python3 log_analyzer.py
